# Sweetch — Android / Shizuku edition

Android-адаптация Sweetch с сохранением узнаваемой визуальной системы оригинала: тёмная красно-чёрная тема, светлая бело-голубая тема, центральный знак S и круговое меню. Добавлен второй вариант меню — пазл, который можно переключать на главном экране.

## Сейчас в репозитории

- Android-приложение на Kotlin + Jetpack Compose.
- Переключаемые тёмная и светлая темы с цветами из оригинального Sweetch.
- Два интерактивных вида меню: круговое и пазл.
- Единый каталог действий для обоих меню.
- Базовый unit-тест каталога действий.
- GitHub Actions собирает debug APK и запускает unit-тесты на push, pull request и вручную.

**Текущий этап — UI-каркас.** Пункты меню пока демонстрируют выбор действия; движки загрузки, Shizuku, обработчик системной комбинации клавиш, перехват контекста, PO Token Provider и реальные файловые операции ещё не подключены.

## Цветовая система

Цвета повторяют палитру оригинального Sweetch:
- Тёмная тема: фон #0D0D11, красный акцент #EB2440, дополнительный красный #AC102D.
- Светлая тема: фон #EDF4FC, синий акцент #1771CB, дополнительный синий #42A5EF.

Оригинальный Windows-проект доступен в [krllmrzv/Sweetch](https://github.com/krllmrzv/Sweetch). Это отдельный проект на C#; Android-приложение реализуется нативно, а не пытается запускать Windows-код на устройстве.

## Сборка

Нужны JDK 17 и Android SDK (API 35). При установленном Gradle 8.9 выполните:

    gradle --no-daemon :app:assembleDebug :app:testDebugUnitTest

APK появится по пути app/build/outputs/apk/debug/app-debug.apk. Успешные сборки GitHub Actions публикуют APK как artifact с именем Sweetch-Shizuku-debug-apk.
